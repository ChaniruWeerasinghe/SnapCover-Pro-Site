# SnapCover Pro

SnapCover Pro is a high-speed, browser-based YouTube thumbnail and asset grabber built with Vanilla JavaScript, HTML5 Canvas, and modern CSS custom properties.

## Features

- **Multi-Format Export**: Convert YouTube JPEGs dynamically into PNG, JPG, or WebP formats losslessly using an offscreen HTML5 Canvas.
- **High-Resolution Support**: Grab Max Res (1080p / 720p), SD (480p), HQ (360p), and MQ (180p) covers.
- **Real-Time URL Validation**: Live parsing of YouTube link inputs with instant feedback.
- **Custom UI Components**: Custom-styled format dropdowns and system-generated Toast notifications (no native browser alerts or select elements).
- **Theme Support**: Seamless Dark Mode and Light Mode with HSL tokens.
- **Vercel Ready**: Single-page setup ready for immediate Vercel hosting.

## Built With

- HTML5 & CSS Custom Properties
- JavaScript (ES6+)
- Canvas API
